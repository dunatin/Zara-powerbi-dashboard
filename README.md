# Zara Sales Analysis Dashboard – Power BI

## Overview
This project is an interactive Power BI dashboard created to analyze Zara sales performance, customer behavior, and business insights.

The dashboard focuses on:
- Sales performance
- Profit analysis
- Customer trends
- Product category insights
- Regional analysis

---

## Tools & Technologies Used
- Power BI
- DAX
- Power Query
- Excel / CSV Dataset

---

## Dataset Information
The dataset includes:
- Sales Amount
- Profit
- Product Categories
- Customer Information
- Regional Data
- Order Details
